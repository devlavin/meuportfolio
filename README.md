# Portfólio — Lavínia Moreira

Site de portfólio pessoal com estética futurista/distópica.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Seções
- **Início** — animação matrix rain com silhueta em canvas
- **Sobre mim** — apresentação e stack de tecnologias
- **Projetos** — galeria com lightbox carrossel
- **Contato** — formulário via Formspree

## Projetos exibidos
- **DinoQuiz** — quiz com login, cadastro e placar
- **GlicoLife** — sistema de controle de glicose
- **Invoria** — sistema de estoque e faturamento
- **Horaí** — plataforma de agendamento

## Funcionalidades
- Animação matrix rain com silhueta humana em canvas
- Lightbox carrossel para visualizar screenshots dos projetos
- Navegação por teclado (← → Esc) no lightbox
- Layout responsivo
- Formulário de contato funcional
